# Cinema Cleaner — guía de playtest FASE 3

Versión: `0.3.0-playtest.2`.

## Cómo abrirlo

1. Extrae por completo el ZIP en una carpeta.
2. Mantén `CinemaCleaner.exe` y `CinemaCleaner.pck` juntos.
3. Ejecuta `CinemaCleaner.exe` y pulsa `Nueva partida`.
4. Si Windows SmartScreen avisa por ser una build sin firma, usa `Más información` → `Ejecutar de todas formas` únicamente si recibiste este ZIP directamente del responsable del TFG.

## Controles

- WASD: movimiento.
- Ratón: cámara.
- Mayús: correr.
- Ctrl: agacharse.
- Espacio: saltar.
- Clic derecho: recoger basura.
- E: interactuar, vaciar, comprar y guardar el reloj.
- Clic izquierdo: tirar el reloj enfocado, con penalización.
- Escape: pausa.

## Qué probar

Juega sin recibir instrucciones adicionales. Intenta terminar la sala, comprar las dos mejoras y abrir la puerta. Después responde:

1. ¿Qué entendiste que debías hacer?
2. ¿Dónde te atascaste?
3. ¿Qué parte te aburrió?
4. ¿Qué acción repetirías?
5. ¿Cuánto tardaste?

Si el juego falla, anota qué estabas haciendo, qué esperabas que ocurriera y qué ocurrió realmente.
