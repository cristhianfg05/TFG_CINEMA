# Lista de prueba manual — FASE 1

Ejecuta el proyecto desde Godot con F6/F5 y prueba durante al menos cinco minutos.

## Controles

- Moverse: W, A, S y D.
- Mirar: ratón.
- Correr: mantener Mayús izquierda.
- Agacharse: mantener Ctrl izquierda.
- Saltar: Espacio.
- Liberar o capturar el ratón: Escape.

## Comprobaciones obligatorias

- [ ] Se puede recorrer toda la sala sin atravesar suelo, paredes, puerta ni butacas.
- [ ] Caminar, correr, saltar y agacharse responden de forma consistente.
- [ ] La cámara no produce mareo durante cinco minutos.
- [ ] Se puede pasar por el pasillo central, los laterales y entre filas.
- [ ] Al agacharse, la cámara permite inspeccionar debajo de las butacas.
- [ ] Si el jugador cae fuera del mapa, reaparece cerca de la entrada.
- [ ] La escala parece coherente: jugador de 1,8 m y puerta de unos 2 m.
- [ ] El proyecto se mantiene por encima de 60 FPS en el equipo de prueba.

## Datos que conviene devolver

- Sensibilidad del ratón: baja / correcta / alta.
- Velocidad al caminar y correr: lenta / correcta / rápida.
- Altura de pie y agachado: baja / correcta / alta.
- FPS mínimo observado.
- Cualquier punto donde el jugador se atasque, indicando fila o pasillo.
