# Primer intento de diálogo ficticio — descartado

Las tres variantes de balbuceo «biribiribiri» se descartaron por indicación del usuario: no tenían la textura buscada. Se retiraron sus tres tomas originales, tres intermedios y tres previews de `audio_source/`; nunca se integraron en Godot. La nueva dirección es un tecleo rápido y suave, similar a una máquina de escribir. Véase [AUDIO_DIALOGUE_SOFT_TYPING_CANDIDATES.md](AUDIO_DIALOGUE_SOFT_TYPING_CANDIDATES.md).
