# PALACE HUD BOLD

Tipografía display original creada para el HUD del juego de limpieza de cine.

ARCHIVOS

- PalaceHUD-Bold.ttf: fuente para importar en Godot.
- PalaceHUD-Specimen.png: muestra visual.

COBERTURA

- Alfabeto latino básico.
- Las minúsculas se muestran como versalitas de la misma altura.
- Números, puntuación habitual y símbolos del HUD.
- ÁÉÍÓÚÜÑ / áéíóúüñ / ¿ / ¡ / € / º / ª.

USO EN GODOT 4

1. Copiar PalaceHUD-Bold.ttf dentro de res://assets/fonts/.
2. Seleccionar la fuente en el panel FileSystem.
3. Activar Multichannel Signed Distance Field (MSDF) en sus opciones de importación.
4. Usarla mediante un Theme global y añadir contorno oscuro para conservar legibilidad.

USO RECOMENDADO

- Títulos: 28–36 px a 1080p.
- Contadores: 26–32 px.
- Interacciones: 20–24 px.
- No usar para párrafos largos.

LICENCIA
Fuente original del proyecto. Se permite usar, modificar y distribuir junto con el videojuego y sus materiales.
