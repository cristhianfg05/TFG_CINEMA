# Funcionalidades de Godot

Usa esta Skill para una funcionalidad nueva.

1. Inspecciona la arquitectura actual y busca sistemas equivalentes.
2. Propón el cambio mínimo que extienda el proyecto sin reescribir sistemas completos.
3. Implementa solo el alcance pedido.
4. Ejecuta el proyecto o la escena relevante, revisa output y errores y prueba la interacción.
5. Si cambia algo visual, captura una imagen con Godot MCP cuando esté disponible.
6. Corrige los errores nuevos y resume los archivos modificados.

No refactorices sistemas enteros si una extensión pequeña resuelve la necesidad.
