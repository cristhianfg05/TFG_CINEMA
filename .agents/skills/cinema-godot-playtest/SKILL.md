# Playtest de Godot

Usa esta Skill después de cambios jugables o visuales.

Con Godot MCP, cuando esté disponible:

1. Ejecuta la escena relevante de forma segura.
2. Comprueba errores y salida de ejecución.
3. Inspecciona el árbol runtime y simula entradas cuando sea útil.
4. Captura screenshots para comprobar que el resultado visual existe realmente.
5. Reporta fallos antes de declarar la tarea terminada.

No cambies escenas principales solo para efectuar una prueba.
